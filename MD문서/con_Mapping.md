\#콘텐츠 매핑 문서  
## 1. 문서의 목적  
본 문서는 금동대향로 가상웹전시에 사용되는 콘텐츠와 각 콘텐츠가 배치되는 화면 및 전시 영역을 연결하기 위한 문서이다.  
전시의 전체적인 구조와 기능은 MD 문서를 기준으로 하며, 본 문서에서는 각 화면에 실제로 사용되는 텍스트, 이미지, 3D 에셋, 영상, 퀴즈 등의 위치와 상태를 관리한다.  
콘텐츠가 변경되거나 추가되는 경우 본 문서를 수정하여 해당 변경 사항을 관리한다.

\### 9. 출처  
-references.md 문서를 참고한다.  
- 각 콘텐츠에서 사용하는 참고문헌은 \[R##] 코드로 표시한다. - 각 콘텐츠에서 사용하는 전시 에셋은 \[A##] 코드로 표시한다. - R/A 코드의 실제 정보는 `references.md`에서 관리한다. - 동일한 자료를 여러 콘텐츠에서 사용하는 경우 동일한 R/A 코드를 사용한다. - 출처와 에셋은 콘텐츠 단위로 연결하며, 개별 문장이나 세부 요소별 출처 대응은 기록하지 않는다. - 실제 참고문헌 및 에셋 정보는 이 문서에 반복해서 작성하지 않는다. - 해당 콘텐츠에 참고문헌 또는 에셋이 없는 경우 해당 항목은 생략한다.
