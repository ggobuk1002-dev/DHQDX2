## 1. `main.md` 대비 변경 및 확장 규칙 (3D 시네마틱 & 동적 수평 시야각 FOV 공식 & 5대 확정 층위)

### 📌 기존 MD 명세
* 백제금동대향로 3D 모델을 로드하고 5대 층위 스크롤에 따라 카메라가 이동하며 텍스트 카드를 보여줌.

### 🚀 추가·확장된 규칙 및 기술적 변경 사항
1. **수평 시야각 불변성 동적 FOV 보정 공식 규칙 (Dynamic Horizontal FOV Matching Rule)**:
   * **문제**: Three.js `PerspectiveCamera`의 기본 수직 시야각(Vertical FOV) 고정 방식으로 인해, 스마트폰 세로 화면(Portrait, 9:16)에서 가로폭이 좁아지며 모델이 비대해지고 양옆이 잘리거나, 가로 ↔ 세로 회전 시 좌표가 튀는 현상 발생.
   * **수학적 보정 알고리즘**:
     $$\text{FOV} = 2 \times \arctan\left(\frac{\tan(\text{BaseFOV} / 2)}{\text{Aspect}}\right) \times \left(\frac{180}{\pi}\right)$$
     * 가로 화면 (`aspect >= 1.0`): 표준 `FOV = 45°` 유지.
     * 세로 화면 (`aspect < 1.0`): 좁아진 가로폭 비율에 맞춰 `FOV = 45° ➔ 68°`로 실시간 자동 확장 (`updateCameraAspect`).
   * **효과**: 가로로 로딩하든, 세로로 로딩하든, 보다가 스마트폰을 회전하든, PC 와이드 모니터든 **모든 기기와 방향에서 향로가 1픽셀의 왜곡 없이 동일한 크기와 완벽한 정중앙 안착 유지**.
2. **5대 층위 표준 공식 명칭 일원화 및 확정 규칙 (Canonical 5-Layer Naming Rule)**:
   * '하늘', '산꼭대기', '꼭대기' 등의 명칭 혼선을 배제하고 아래의 **5대 표준 공식 명칭으로 100% 확정 및 통일**:
     * **1층위: `천상`** (`celestial`) - 봉황 18번 (하늘을 품은 날갯짓, 턱 밑에 여의주를 품은 신조)
     * **2층위: `산마루`** (`sky`) - 신선들의 선율이 흐르는 봉우리, 다섯 악사의 신선 세계 (금·완함·동고·종적·소)
     * **3층위: `삼신산`** (`land`) - 첩첩산중 생명의 터전, 12종 산림·육지·조류 생태계
     * **4층위: `연꽃과 물가`** (`water`) - 활짝 핀 연꽃과 수변 생태계, 5종 수생·수변 생물군
     * **5층위: `바다`** (`sea`) - 용 19번 (용트림하며 향로를 떠받치는 불멸의 생명력)
3. **가로/세로 모드 5대 층위별 초점(Target Y) 절대 통일 규칙**:
   * 5대 층위의 초점(`Target LookAt`)을 향로의 중심축(`X: 0`)과 일치하는 절대 Y좌표로 완전 통일하여, 화면 회전 시 시선의 덜컹거림을 완벽 방지:
     * `천상`: Target `Y: 0.50`
     * `산마루`: Target `Y: 0.28`
     * `삼신산`: Target `Y: 0.08`
     * `연꽃과 물가`: Target `Y: -0.15`
     * `바다`: Target `Y: -0.38`
4. **카메라 시선 보간 벡터(`currentLookAt`) 렌더링 무결성 규칙**:
   * 렌더 루프(`animate()`)에서 부드러운 LERP 시선 추적을 위해 `this.currentLookAt` 인스턴스를 항상 안전하게 유지하여 PC/모바일 전 환경에서 60fps 무중단 렌더링 보장.
5. **국립박물관 실물 명암 대비(Chiaroscuro) 조명 규칙**:
   * `ambientLight`를 `0.0`으로 설정하여 빛이 닿지 않는 음영을 칠흑 같은 어둠의 실루엣으로 처리.
   * `0x38bdf8` 사이언/블루 컬러의 **일식 림 라이트(`eclipseRimLight` = 12.0)**를 후방에 배치하여 `intro.jpg`의 신비로운 역광 후광(`eclipseGlow`) 재현.
   * 전방 골드 키 라이트(`goldKeyLight` = 0.45, `0xd4af37`)와 상단 림 라이트(`1.2`) 조합으로 금동 조각의 윤곽선 극대화.
6. **층위별 텍스트-모델 시각 충돌 방지 대향 오프셋(Opposite Offset) 규칙**:
   * 설명 카드가 화면 우측에 위치할 때는 향로 모델을 좌측(`X: -0.60 ~ -0.65`)으로, 설명 카드가 좌측에 위치할 때는 향로 모델을 우측(`X: +0.60 ~ +0.65`)으로 자동 오프셋하여 **텍스트 카드가 3D 향로를 가리는 현상을 100% 원천 차단**.
7. **1-화면 스크롤 스냅 휠 컨트롤러 규칙 (`initWheelSnapController`)**:
   * PC 환경에서 마우스 휠 조작 시 1번의 휠 굴림마다 다음/이전 층위 카드로 부드럽게 스냅 이동.
   * **모달 배제 규칙**: 참고문헌 모달이나 해설사 모달이 열려 있을 때는 메인 휠 스냅을 즉시 비활성화하여 모달 내부 스크롤 보장.
* **관련 소스 파일**: `js/threeViewer.js`, `js/app.js`, `css/style.css`
