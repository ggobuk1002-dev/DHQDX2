# **금동대향로 웹 전시 — 상세 동물 보기 댓글 시스템**

## **1\. 구현 목적**

금동대향로 웹 전시의 **상세 동물 보기 페이지 최하단**에 관람객이 서로 의견을 남기고 소통할 수 있는 댓글 시스템을 추가한다.

댓글 시스템은 단순한 일회성 댓글 목록이 아니라 다음 기능을 모두 지원해야 한다.

* 동물별 독립적인 댓글  
* 댓글 작성  
* 댓글 추천  
* 추천 취소  
* 댓글에 대한 답글  
* 답글에 대한 답글  
* **무제한 댓글 중첩**  
* 추천 수가 가장 높은 댓글 TOP 3  
* 인기 댓글 실시간 순위 변경  
* 댓글 및 답글의 상태 유지

기존 금동대향로 웹 전시의 디자인과 자연스럽게 어울리도록 구현하며, 기존 상세 동물 콘텐츠의 레이아웃이나 기능을 훼손하지 않는다.

---

댓글 영역은 **상세 동물 콘텐츠가 모두 끝난 페이지의 가장 아래**에 배치한다.

전체 구조는 다음과 같다.

        ↓  
기존 상세 콘텐츠  
        ↓  
────────────────────────  
💬 관람객의 한마디  
        ↓  
⭐ 인기 댓글 TOP 3  
        ↓  
전체 댓글  
        ↓  
댓글 입력창

댓글 영역 때문에 기존 동물 이미지나 설명 영역의 크기와 배치를 변경하지 않는다.

# **4\. 동물별 댓글 데이터**

댓글은 모든 동물이 동일한 댓글을 공유하지 않는다.

**현재 상세 페이지에서 선택된 동물에 따라 서로 다른 댓글 데이터를 표시한다.**

예:

수달 → 수달 댓글  
해달 → 해달 댓글  
용 → 용 댓글  
금시조 → 금시조 댓글  
악어 → 악어 댓글  
코끼리 → 코끼리 댓글  
닭 → 닭 댓글

현재 프로젝트에서 사용하는 **동물 고유 ID를 댓글 데이터의 key로 사용한다.**

예:

const animalComments \= {  
  otter: \[\],  
  seaOtter: \[\],  
  dragon: \[\],  
  geumsijo: \[\],  
  crocodile: \[\],  
  elephant: \[\],  
  chicken: \[\]  
};

각 동물의 댓글 데이터는 완전히 독립적으로 관리한다.

수달 페이지에서 작성한 댓글은 해달 페이지에 나타나면 안 된다.

수달의 추천 수와 해달의 추천 수도 서로 독립적이어야 한다.

# **6\. 댓글 데이터 구조**

댓글과 답글은 **완전히 동일한 데이터 구조**를 사용한다.

{  
  id: "unique-id",  
  name: "김○○",  
  text: "댓글 내용",  
  likes: 24,  
  createdAt: timestamp,  
  replies: \[\]  
}

각 댓글은 자신의 `replies` 배열을 가진다.

답글 역시 동일한 구조를 사용한다.

{  
  id: "unique-id",  
  name: "박○○",  
  text: "답글 내용",  
  likes: 7,  
  createdAt: timestamp,  
  replies: \[\]  
}

따라서 다음과 같은 구조가 가능해야 한다.

댓글  
 └─ 답글  
     └─ 답글  
         └─ 답글  
             └─ 답글  
                 └─ 답글  
                     └─ 계속...

# **7\. 무제한 댓글 중첩**

**댓글 중첩 깊이에 제한을 두지 않는다.**

댓글의 답글에도 답글을 달 수 있어야 하며, 그 답글에도 다시 답글을 달 수 있어야 한다.

예:

김○○  
수달이 정말 귀여워요\!  
👍 24   답글

  ↳ 박○○  
  저도 수달이 제일 귀여웠어요\!  
  👍 12   답글

    ↳ 이○○  
    저는 해달도 귀엽더라고요\!  
    👍 8   답글

      ↳ 최○○  
      둘이 비슷하게 생겨서 처음엔 구분하기 어려웠어요.  
      👍 5   답글

        ↳ 정○○  
        코 모양을 보면 쉽게 구분할 수 있어요.  
        👍 3   답글

          ↳ 김○○  
          아 그렇군요\!  
          👍 1   답글

            ↳ 계속 가능

**2단계, 3단계 등의 제한을 코드에 넣지 않는다.**

# **8\. 재귀 렌더링**

무제한 중첩을 구현하기 위해 댓글 UI는 **재귀적인 방식으로 렌더링**한다.

개념적인 구조:

function renderComment(comment, depth \= 0\) {

  // 댓글 내용 표시

  // 추천 버튼 표시

  // 답글 버튼 표시

  // 답글 입력창 표시

  // replies가 존재한다면  
  // 각각의 reply에 대해 renderComment(reply, depth \+ 1\)

}

`replies` 안에 또 `replies`가 존재하면 동일한 렌더링 함수를 계속 호출한다.

데이터 구조상 중첩 깊이를 제한하지 않는다.

# **10\. 답글 기능**

모든 댓글과 모든 답글에는 **답글 버튼**을 표시한다.

사용자가 `답글` 버튼을 누르면 해당 댓글 바로 아래에 답글 입력창을 표시한다.

Placeholder:

이 댓글에 답글을 남겨보세요.

버튼:

\[ 등록 \] \[ 취소 \]

등록하면 해당 댓글의 `replies` 배열에 새 답글을 추가한다.

새로 작성된 답글 역시 동일한 댓글 구조를 가지며 `답글` 버튼을 제공한다.

따라서 새 답글에도 다시 답글을 작성할 수 있다.

# **12\. 추천 기능**

모든 댓글과 모든 답글에 **추천 기능**을 제공한다.

예:

👍 12

추천 버튼을 누르면:

👍 13

으로 증가한다.

다시 누르면 추천을 취소한다.

👍 13  
↓  
👍 12

추천 수는 각 댓글마다 독립적으로 관리한다.

---

# **13\. 답글에도 추천 기능 적용**

추천 기능은 최상위 댓글뿐만 아니라 **모든 중첩 답글에도 적용**한다.

예:

댓글 👍 20  
 └─ 답글 👍 15  
     └─ 답글 👍 8  
         └─ 답글 👍 3

각각의 추천 수는 독립적으로 관리한다.

부모 댓글의 추천 수와 답글의 추천 수를 합산하지 않는다.

---

# **14\. 중복 추천 방지**

한 사용자가 같은 댓글에 반복해서 추천하여 추천 수를 무한히 증가시키지 못하도록 한다.

현재 별도의 로그인 시스템이 없다면 **현재 브라우저 기준으로 추천 여부를 저장**한다.

가능하면 `localStorage`를 활용한다.

예:

localStorage.setItem(  
  \`liked-comment-${comment.id}\`,  
  "true"  
);

추천을 취소하면 해당 상태도 변경한다.

페이지를 새로고침해도 현재 브라우저의 추천 상태가 유지되도록 한다.

# **15\. 인기 댓글 TOP 3**

댓글 영역의 가장 위에 다음 섹션을 표시한다.

⭐ 인기 댓글

현재 동물의 **최상위 댓글만** 대상으로 추천 수를 비교한다.

추천 수가 가장 높은 댓글 **상위 3개**를 선정하여 표시한다.

예:

⭐ 인기 댓글

🥇 김○○  
수달이 물속에서 헤엄치는 모습이 정말 귀여워요\!  
👍 24    답글

🥈 박○○  
해달과 수달의 차이를 처음 알았어요.  
👍 19    답글

🥉 이○○  
금동대향로에 이렇게 다양한 동물이 있다는 게 신기해요.  
👍 15    답글

# **16\. 인기 댓글 선정 기준**

**최상위 댓글만 인기 댓글 선정 대상에 포함한다.**

예:

댓글 A 👍 20  
 └─ 답글 A-1 👍 100

댓글 B 👍 30

답글 A-1의 추천 수가 100이더라도 인기 댓글 순위에는 포함하지 않는다.

결과:

🥇 댓글 B 👍 30  
🥈 댓글 A 👍 20

가 된다.

---

# **17\. 인기 댓글 정렬**

추천 수가 높은 순서대로 정렬한다.

const popularComments \= topLevelComments  
  .sort((a, b) \=\> {  
    if (b.likes \!== a.likes) {  
      return b.likes \- a.likes;  
    }

    return a.createdAt \- b.createdAt;  
  })  
  .slice(0, 3);

추천 수가 동일한 경우 **먼저 작성된 댓글을 우선**한다.

댓글이 3개 미만이면 존재하는 댓글만 표시한다.

댓글이 하나도 없다면 `⭐ 인기 댓글` 영역을 표시하지 않는다.

# **18\. 인기 댓글 실시간 갱신**

사용자가 댓글을 추천하거나 추천을 취소하면 추천 수에 따라 인기 댓글 순위를 즉시 다시 계산한다.

예:

현재

🥇 A 👍 20  
🥈 B 👍 18  
🥉 C 👍 15

B 댓글에 추천하여 19가 되면:

🥇 A 👍 20  
🥈 B 👍 19  
🥉 C 👍 15

B가 21이 되면:

🥇 B 👍 21  
🥈 A 👍 20  
🥉 C 👍 15

처럼 즉시 변경한다.

새로 작성한 댓글 역시 추천 수가 증가하여 TOP 3에 진입하면 자동으로 인기 댓글 영역에 표시한다.

# **19\. 인기 댓글과 전체 댓글 데이터 공유**

매우 중요하다.

인기 댓글을 별도의 복사본으로 만들지 않는다.

**인기 댓글과 전체 댓글은 동일한 원본 댓글 데이터를 참조해야 한다.**

예:

⭐ 인기 댓글

김○○  
👍 24

────────────────

전체 댓글

김○○  
👍 24

인기 댓글에서 추천을 누르면 전체 댓글의 추천 수도 즉시 변경되어야 한다.

전체 댓글에서 추천을 눌러도 인기 댓글의 추천 수가 즉시 변경되어야 한다.

인기 댓글에서 답글을 작성하면 전체 댓글의 동일한 댓글에도 해당 답글이 즉시 나타나야 한다.

# **20\. 인기 댓글의 답글**

인기 댓글에서도 일반 댓글과 동일한 기능을 제공한다.

가능한 기능:

* 추천  
* 추천 취소  
* 답글 작성  
* 기존 답글 표시  
* 답글의 답글 작성  
* 무제한 중첩

인기 댓글은 단순한 미리보기 카드가 아니라 **실제 댓글 객체를 사용하는 동일한 댓글 UI**여야 한다.

# **21\. 동물 변경**

상세 동물 보기에서 다른 동물로 이동하면 댓글 영역도 해당 동물의 데이터로 변경한다.

예:

수달  
 ↓  
해달

수달의 댓글과 답글은 표시하지 않고 해달의 댓글과 답글만 표시한다.

각 동물의 댓글, 답글, 추천 수, 추천 상태는 서로 독립적이어야 한다.

# **24\. 댓글 저장**

현재 프로젝트에 백엔드 또는 데이터베이스가 존재한다면 기존 저장 시스템에 맞춰 댓글 데이터를 저장한다.

백엔드가 없는 경우 최소한 현재 브라우저에서 새로고침해도 다음 상태가 유지되도록 한다.

* 댓글  
* 답글  
* 추천 수  
* 사용자의 추천 여부

가능하면 `localStorage` 등을 활용한다.

추후 실제 여러 사용자가 댓글을 공유할 수 있는 서비스로 확장할 수 있도록 댓글 데이터 구조와 UI 로직을 분리한다.

# **25\. UI 디자인**

기존 금동대향로 웹 전시의 디자인과 자연스럽게 통합한다.

* 기존 폰트 사용  
* 기존 색상 체계 사용  
* 기존 카드 및 버튼 스타일과 통일  
* 지나치게 현대적인 SNS 스타일을 피한다.  
* 전시 페이지의 차분하고 깔끔한 분위기를 유지한다.  
* 댓글 사이에 충분한 여백을 둔다.  
* 답글은 들여쓰기로 계층 구조를 명확하게 표시한다.  
* 추천 버튼은 작고 직관적으로 배치한다.  
* 인기 댓글 TOP 3는 일반 댓글보다 살짝 강조한다.  
* 과도한 그림자나 큰 카드 사용을 피한다.  
* 데스크톱과 모바일 모두 반응형으로 구현한다.

중첩 댓글이 매우 깊어지더라도 모바일 화면의 가로 영역이 지나치게 좁아지지 않도록 처리한다.

데이터의 중첩 깊이는 무제한으로 유지하되, 시각적인 들여쓰기 폭은 화면 너비에 맞게 조정할 수 있다.

# **27\. 최종 구현 체크리스트**

다음 항목을 **모두 구현해야 한다.**

* 상세 동물 페이지 최하단에 댓글 영역 추가  
* `💬 관람객의 한마디` 제목 표시  
* 동물마다 서로 다른 댓글 데이터 사용  
* 동물별 댓글 데이터 독립 관리  
* 기본 예시 댓글 1\~3개 제공  
* 새 댓글 작성 가능  
* 댓글 추천 가능  
* 추천 취소 가능  
* 추천 중복 방지  
* 추천 상태 유지  
* 답글 작성 가능  
* 답글에도 추천 가능  
* 답글에도 답글 작성 가능  
* **댓글 중첩 깊이 무제한**  
* 재귀적인 댓글 렌더링  
* 각 댓글이 `replies` 배열을 가짐  
* 최상위 댓글 추천 수 기준 인기 댓글 TOP 3 선정  
* 인기 댓글을 댓글 영역 최상단에 표시  
* 인기 댓글과 전체 댓글이 동일한 원본 데이터 사용  
* 추천 수 변경 시 인기 댓글 순위 실시간 갱신  
* 새 댓글도 추천 수에 따라 TOP 3 진입 가능  
* 추천 수가 같으면 먼저 작성된 댓글 우선  
* 댓글이 3개 미만이면 존재하는 댓글만 표시  
* 댓글이 없으면 인기 댓글 영역 숨김  
* 인기 댓글에서도 추천 및 답글 기능 사용 가능  
* 동물 변경 시 해당 동물의 댓글만 표시  
* 동물별 추천 수 독립 관리  
* 댓글과 답글의 추천 수 독립 관리  
* 빈 댓글 등록 방지  
* 빈 답글 등록 방지  
* 댓글 등록 후 즉시 화면 반영  
* 현재 브라우저에서 댓글 및 추천 상태 유지  
* 모바일 반응형 지원  
* 데스크톱 반응형 지원  
* 기존 금동대향로 전시 디자인과 통일  
* 기존 상세 동물 콘텐츠의 레이아웃을 훼손하지 않음

## **가장 중요한 구현 원칙**

**1\. 댓글은 동물별로 독립되어야 한다.**

**2\. 댓글과 답글은 동일한 데이터 구조를 사용한다.**

**3\. 댓글 중첩 깊이는 제한하지 않는다.**

**4\. 모든 댓글과 답글에 추천 기능을 제공한다.**

**5\. 인기 댓글 TOP 3는 최상위 댓글의 추천 수만 기준으로 선정한다.**

**6\. 인기 댓글과 전체 댓글은 동일한 원본 데이터를 사용한다.**

**7\. 추천 수가 변경되면 인기 댓글 순위도 즉시 갱신한다.**

**8\. 기존 전시 UI를 유지하면서 페이지 최하단에 자연스럽게 통합한다.**
